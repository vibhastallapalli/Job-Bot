Must match the redirect URI registered in Azure exactly.
Azure App Registration — step-by-step
  1. Go to portal.azure.com and sign in with the Microsoft account you use for Outlook.
  2. Search for Azure Active Directory (or Microsoft Entra ID) → App registrations → + New registration.
  3. Name: anything (e.g. job-bot). Supported account types: Single tenant for work/school, Multitenant + personal for @outlook.com / @hotmail.com.
  4. Redirect URI platform: Web. URI: http://localhost:5000/email/auth/callback. Click Register.
  5. On the Overview page copy Application (client) ID → paste above.
  6. Copy Directory (tenant) ID → paste above (or use common for personal accounts).
  7. Go to Certificates & secrets → + New client secret. Set any expiry, click Add, copy the Value immediately → paste above as Client Secret.
  8. Go to API permissions → + Add a permission → Microsoft Graph → Delegated → search Mail.Read → Add.
  9. If your org requires it: click Grant admin consent. Personal accounts skip this step.
  10. Save settings here, then click Connect Outlook on the Dashboard.
